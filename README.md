# 통합 점 사이트

생년월일과 MBTI, 혈액형, 성별만 넣으면 열한 가지 점술이 한 번에 돌아갑니다.
그리고 **그 열 가지가 서로 어디서 동의하고 어디서 싸우는지**를 보여줍니다.

점술을 나란히 나열하는 사이트는 이미 많습니다. 이 프로젝트가 하려는 건 그게 아니라,
여러 체계를 하나의 성향 축 위에 올려놓고 비교하는 것입니다. 사주는 화(火)가 몰렸다고
하는데 MBTI는 INFP라고 할 때, 그 어긋남 자체를 결과로 보여줍니다.

## 들어있는 것

| 점술 | 계산 근거 |
| --- | --- |
| 오늘의 운세 | 생년월일과 날짜를 시드로 한 결정론적 결과. 현재 대운 등급을 점수에 반영 |
| 대운 | 사주 기반 10년 주기 인생 시간표. 현재 위치, 다음 전환 시점, 전성기 |
| 한국 사주 | 만세력 기반 사주팔자, 절기 기준 월주, 일간 물상, 계절, 오행 분포 |
| 십이지 띠 | 음력설·입춘 두 기준 모두. 삼합·육합·충 궁합 |
| 서양 별자리 | 태양별자리, 원소 궁합, 대칭 별자리 |
| 태국 요일점 | 요일별 수호색·불상·행성. 수요일은 낮/밤을 나눈 여드레 체계 |
| 수비학 | 생년월일 자릿수 합으로 구한 라이프패스, 마스터 넘버 보존, 궁합 숫자 |
| 마야 촐킨 | GMT 상관계수(584283) 기준 KIN·톤·인장 |
| MBTI | 입력값. 네 글자 + 기질 조합 |
| 혈액형 × 별자리 | 입력값과 별자리 원소의 조합 |
| 탄생석·탄생화 | 월별 |

오늘의 운세와 대운은 성격이 달라서 카드 목록에 들어가지 않고 별도 섹션으로 나갑니다.
나머지 아홉 가지가 접히는 카드로 붙습니다.

## 대운

이 프로젝트에서 유일하게 **시간축**을 가진 항목입니다. 나머지는 전부 "당신은 이런 사람"을
말하는데 대운만 "언제 무엇이 바뀌는지"를 말합니다.

- 방향은 성별에 따라 갈립니다. 양남음녀는 순행, 음남양녀는 역행입니다. 그래서 입력에 성별이 필요합니다.
- 각 대운 10년이 사주에 도움이 되는지를 점수로 매기고, 가장 높은 구간을 전성기로 봅니다.
- 신강·신약을 먼저 판정하고, 신약이면 보태주는 기운(인성·비겁)을, 신강이면 덜어내는 기운(식상·재성·관성)을 좋게 칩니다.
- 십신 그룹마다 그 시기의 화두가 붙습니다. 대운이 바뀌면 화두가 무엇에서 무엇으로 옮겨가는지 보여줍니다.

점수를 도움/방해 두 값으로만 주면 천간과 지지가 서로 상쇄돼 전부 0으로 뭉칩니다.
그러면 전성기를 고를 수 없어서, 그룹마다 세기를 나누고 지지에 더 무거운 가중치를 줍니다.
전성기 후보에서 유년기는 뺐습니다. 다섯 살이 인생의 전성기라는 결과는 아무 의미가 없습니다.

## 구조

핵심은 `src/core/`입니다.

- `axes.ts` — 모든 점술이 공유하는 성향 축 다섯 개(내향↔외향, 침착↔열정, 즉흥↔계획, 이상↔현실, 독립↔관계)
- `consensus.ts` — 축별 평균과 표준편차로 합의도와 최대 충돌 지점을 뽑는다

점술 하나가 엔진 하나(`src/engines/*.ts`)이고, 모든 엔진은 `Reading`을 돌려줍니다.
`Reading.axes`에 축 점수를 넣으면 자동으로 합의도 계산에 참여합니다.
**항목을 스무 개로 늘려도 이 축에만 맞추면 요약 화면은 그대로 돌아갑니다.**

축에 참여하지 않으려면 `axes: {}`로 두면 됩니다. 탄생석이 그렇습니다.
성향과 무관한 값이라 합의도를 흐리기 때문입니다.

## 원칙

**계산과 해석을 분리합니다.** 사주 간지, 촐킨 KIN, 라이프패스는 정답이 있는 계산이고,
그 위에 붙는 해석 문장은 전부 정적 데이터입니다. 런타임에 문장을 생성하지 않습니다.

**같은 입력이면 항상 같은 결과가 나옵니다.** 오늘의 운세처럼 흔들릴 여지가 있는 항목도
생년월일과 날짜를 시드로 한 해시에서 뽑습니다(`src/core/rng.ts`).

**서버가 없습니다.** 계산이 전부 브라우저 안에서 끝나서 생년월일이 밖으로 나가지 않습니다.
대신 결과별 OG 이미지를 만들 수 없어서, 공유는 canvas로 그린 PNG를 내려받는 방식입니다.

## 디자인

먹빛 바탕에 금색 하나만 포인트로 씁니다. 금색을 아껴 쓰고 나머지를 거의 무채색으로 두는 게
유일한 규칙입니다. 색을 하나 더 늘리고 싶어지면 여백이나 글자 크기로 먼저 풀어보세요.

- 본문은 Pretendard, 제목과 인용은 **고운바탕**(국문 명조). 이 대비가 화면 인상을 거의 다 만듭니다.
- 합의도는 원형 눈금입니다. 이 화면에서 제일 먼저 눈에 들어와야 하는 숫자라서요.
- 자간을 크게 준 라벨에 숫자가 섞이면 "11"이 "1 1"로 읽힙니다. 숫자가 들어가는 라벨은 자간을 낮게 둡니다.
- 공유 카드(canvas)는 CSS와 같은 색 값을 씁니다. 둘이 어긋나면 저장한 이미지만 딴 사이트처럼 보입니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버
npm run build      # 정적 빌드 → dist/
npm run smoke      # 샘플 입력 네 건으로 엔진 전체 확인
npm run dist       # 3000건 돌려 합의도 분포와 충돌 축 분포 확인
npm run ddi        # 띠가 갈리는 날 비율 실측
```

`npm run dist`는 합의도 눈금을 조정할 때 씁니다. 점수가 한 구간에 몰리면
게이지가 정보를 주지 못하므로, 분포를 보고 `consensus.ts`의 `STRETCH`를 조정합니다.

## 정확도에 대해

전부 재미로 보는 것이고 과학적으로 검증된 항목은 하나도 없습니다.
다만 계산이 있는 부분은 틀리지 않게 했습니다.

- 사주 월주와 년주는 **입춘 기준**으로 갈립니다. 양력 1월 1일이나 음력 설이 아닙니다.
- 띠는 관습적으로 음력설 기준이라 사주와 다를 수 있습니다. 둘 다 보여주고 다르면 표시합니다.
- 마야 촐킨은 2012-12-21이 `4 Ahau, KIN 160`으로 나오는 걸 확인했습니다.
- 띠 궁합의 삼합·육합·충은 명리 규칙 그대로입니다.
- 대운 방향과 시작 나이는 만세력 라이브러리가 계산합니다. 1995-07-14는 남자가 역행 3세, 여자가 순행 9세로 나오고 이는 음남역행·음녀순행 규칙과 맞습니다.

반대로 확실하지 않은 부분은 화면에 그대로 적어뒀습니다.
대운에서 신강·신약을 판정하고 좋은 기운을 고르는 방식은 유파마다 다릅니다.
여기서는 월지를 가장 무겁게 보는 간이 방식이고 지장간과 합충은 보지 않습니다. 이것도 화면에 적어뒀습니다. 태국 요일점의 불상 자세와
행성 배정은 자료마다 다르고, 탄생석 목록도 나라마다 다릅니다.
혈액형 성격론은 여러 연구에서 반복적으로 부정됐다는 사실을 결과 안에 적어뒀습니다.

## 남은 것

- 번들이 537KB입니다. 대부분 만세력 라이브러리(`lunar-javascript`)라 사주 엔진만 동적 import로 떼면 초기 로딩이 줄어듭니다.
- 별자리는 태양별자리만 봅니다. 달·상승궁까지 보려면 천체력이 따로 필요합니다.
- 결과 URL 공유(쿼리스트링에 입력값을 실어 링크로 여는 방식)는 아직 없습니다.
